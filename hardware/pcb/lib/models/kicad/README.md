# KiCad library 3D models

Copies of the KiCad 3D models this board uses, from
[kicad-packages3D](https://gitlab.com/kicad/libraries/kicad-packages3D)
at tag 10.0.8, so renders need no download. They are the KiCad Library
Team's work, under CC-BY-SA 4.0 with KiCad's exception for designs that
use them: https://www.kicad.org/libraries/license/

`scripts/fetch-kicad-models.sh` adds any model a new footprint needs.
